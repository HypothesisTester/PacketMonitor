# PacketMonitor payload signatures
#
#   <severity> <name> "<content>" [nocase] : <alert message>
#
# severity: low, medium or high. In content, |0d 0a| is bytes in hex and
# \" \\ \| are those characters. nocase matches letters in any case.
# Matching follows each TCP stream, so content split across packets is found.

# Test content: safe ways to check the tool works.
high   eicar-test-file      "X5O!P%@AP[4\\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!" : EICAR antivirus test file

# Credentials and data sent without encryption.

medium ftp-login            "|0d 0a|PASS "                           : Password sent unencrypted (FTP or POP3)
low    http-cookie-session  "|0d 0a|cookie: session"         nocase : Session cookie sent unencrypted
